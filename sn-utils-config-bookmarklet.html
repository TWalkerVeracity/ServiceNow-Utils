📖 How to Use

Backup Your Configuration:

  • Go to any ServiceNow instance
  • Click the bookmarklet in your bookmarks bar
  • Click the "💾 Backup Config" button
  • A JSON file will be downloaded with all your instance tag configurations

Restore Your Configuration:

  • Go to any ServiceNow instance
  • Click the bookmarklet in your bookmarks bar
  • Click the "📥 Restore from File" button
  • Select your previously saved backup JSON file
  • Your configurations will be restored and the page will reload

View Your Configuration:

  • Click the "👁️ View Config" button
  • Open the browser console (F12) to see all your current configurations
💡 Pro Tip: Create backups regularly, especially before making major changes to your instance tags or when switching browsers!

🔍 What Gets Backed Up?

The bookmarklet backs up all instance-specific configurations including:

  • tagText - The text displayed on the instance marker
  • tagFontSize - Font size of the marker
  • tagFontColor - Text color
  • tagTagColor - Background color (the favicon override color)
  • tagOpacity - Transparency level
  • tagLeft / tagBottom - Position on screen
  • tagCommand / tagCommandShift / tagTextDoubleclick - Custom commands
  • tagEnabled - Whether the tag is enabled

⚠️ Important Notes

  • This bookmarklet requires the SN Utils extension to be installed
  • You must be on a ServiceNow instance page for it to work properly
  • Backup files are saved locally to your Downloads folder
  • Restoring will overwrite existing configurations for matching instances
  • The page will automatically reload after restoring configurations

🐛 Troubleshooting

  • Nothing happens when I click the bookmarklet? Make sure you're on a ServiceNow instance page and have the SN Utils extension installed.
  • "No configs found"? You may not have configured any instance tags yet. Try setting up an instance tag first using the SN Utils extension.
  • Restore not working? Check that the JSON file is valid and was created by this bookmarklet.
